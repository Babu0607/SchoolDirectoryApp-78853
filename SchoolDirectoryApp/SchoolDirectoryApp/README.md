# School Directory Dashboard

A Blazor Web Application built with .NET 8 that consumes data from the Edutots School API and presents school information through a clean, responsive, and interactive user interface.


# Overwiew
This application allows users to search, filter, and inspect detailed profiles for various schools. Built using server-side interactivity InteractiveServer, component-based architecture, proper state management, and custom Bootstrap styling.

# Features
API Integration: Fetches and deserializes school data from the Edutots School API.
Component Architecture: Reusable 'SchoolCard' and 'SchoolDetails' components using '[Parameter]' and 'EventCallback'.
Real-time Search: Filters schools dynamically as the user types.
State Handling: Implements loading indicators and graceful error handling.
* Responsive Layout: Clean CSS grid and card design built with Bootstrap 5.

# Technologies Used
* Framework: .NET 8 blazor server InteractiveServer
* Language: C#
* Styling: Bootstrap 5 & Custom CSS
* ata Source: Edutots School API
* Version Control: Git & GitHub



# API Endpoint Used
* Base URL:** `https://edutots.net/api/school`
